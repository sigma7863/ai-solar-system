# ai-solar-system

太陽系シミュレーターのコレクション。Three.js + Vite + Bun で構築。

## サブプロジェクト

| プロジェクト | 説明 |
|---|---|
| `solar-system-big-pickle` | 太陽系シミュレーター |
| `solar-system-deepseek-v4-flash-free` | 太陽系シミュレーター（DeepSeek V4 Flash バージョン） |
| `solar-system-hy3-free` | 太陽系シミュレーター（HY3 バージョン） |
| `solar-system-mimo-v2.5-free` | 太陽系シミュレーター（MIMO v2.5 バージョン） |
| `solar-system-nemotron-3-ultra` | 太陽系シミュレーター（Nemotron 3 Ultra バージョン） |

## 主な機能

- 太陽系惑星の3D描画（Three.js）
- 惑星の公転・自転アニメーション
- カメラ操作（ズーム・回転）

## 技術スタック

- Three.js
- TypeScript
- Vite
- Bun

## セットアップ

各サブプロジェクトディレクトリで実行：

```bash
bun install
bun run dev
```

`http://localhost:5173` でアクセスできます。
